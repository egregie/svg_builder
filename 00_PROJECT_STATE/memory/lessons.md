# Извлечённые уроки

- **Урок**: Тестировать пайплайн на реальных данных, а не на искусственных заглушках.
  - *Обоснование*: Заглушки скрывают проблемы масштабирования, разницы viewBox и шума в растрах, которые сразу проявились при переходе к реальным файлам.
- **Урок**: Обязательная PIL-санитизация PNG до передачи в VTracer.
  - *Обоснование*: Некоторые профили sRGB и альфа-каналы вызывают предупреждения libpng и ошибки декодирования в Rust-библиотеке.
- **Урок**: Валидация XML через `xml.etree.ElementTree` должна выполняться прямо на этапе генерации, а не только на этапе QA.
  - *Обоснование*: Позволяет локализовать синтаксические ошибки невалидных путей сразу в момент их формирования.
- **Правило фиксации состояния (Git Commit Rule)**:
  - *Обоснование*: Перед началом любого задания делать коммит только при наличии изменений в статусе `PENDING CHANGES`. После каждого ТЗ обновлять `00_PROJECT_STATE` и делать коммит.
