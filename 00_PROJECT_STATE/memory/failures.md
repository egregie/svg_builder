# Хронология провалов и ошибок

- **2026-06-11**: Пустые / одноцветные SVG на выходе при первом запуске на реальных PNG. Причина: VTracer возвращал фоновые контуры вместе с целевыми фигурами, закрашивая весь холст. Решение: Внедрен алгоритм фильтрации путей по RGB-расстоянию до токенов.
- **2026-06-11**: CPU-only torch при попытке запуска StarVector INT4. Причина: Отсутствие корректно настроенных CUDA библиотек в Python-окружении Windows. Решение: Валидация и доустановка зависимостей.
- **2026-06-11**: viewBox-мисматч COMP-001. Причина: Различие разрешения исходного растра и целевого canvas приводило к смещению контуров. Решение: Добавление автоматического тега `transform="scale(...) translate(...)"` при композиции слоев.
