# Архитектурные принципы и уроки проекта

- **Семантическое разделение**: Метаданные (паспорта) отделены от графического представления (SVG). Это гарантирует строгую проверку структуры до начала дорогостоящей сборки.
- **Локальный инференс и Fallback-стратегии**: В системах локального ИИ на Windows необходимо предусматривать программный fallback (например, замена нейросетевого StarVector на оптимизированный алгоритмический VTracer) на случай падения библиотек типа `fairscale`.
- **Строгая гигиена репозитория (Git Commit Rules)**:
  1. Перед выполнением нового задания делать коммит только в том случае, если в проекте присутствуют измененные файлы (Pending Changes).
  2. После выполнения каждого ТЗ обязательно обновить файлы состояния в папке `00_PROJECT_STATE` и сделать коммит.
