# Лог архитектурных решений

- **Foundation-First парадигма**: Сначала строится прочная база дизайн-токенов и онтологии, только затем запускаются сборочные этапы.
- **Промежуточный паспорт объекта как декларативный слой**: Все метаданные деконструкции фиксируются в `COMP-*.md` и `COMP-*.json` перед финальным рендером. Это позволяет валидировать слои отдельно от компиляции SVG.
- **Выбор VTracer + StarVector (не облако)**: Локальный инференс без обращения к внешним API обеспечивает полную конфиденциальность и автономность.
- **Zero Black Policy**: Полный запрет на использование чисто черного (#000/#000000) и чисто белого (#FFF/#FFFFFF) цветов в стилях элементов. Замена на семантические токены (`--dark`, `--white`, `--bg`).
- **Стратегия цветовой фильтрации через RGB-расстояние**: Определение близости фактического цвета фигуры к токенам для отсечения фоновых подложек.
- **Windows-native INT4 вместо WSL2**: Запуск локального инференса StarVector непосредственно в ОС Windows для исключения накладных расходов виртуализации.
