# Входящие растровые файлы для деконструкции (input/)

Данная папка является единой точкой входа для всех растровых изображений, предназначенных для деконструкции и последующей векторной сборки.

## Правила именования файлов
Все файлы, помещаемые в эту папку, должны соответствовать шаблону:
`[описание]_[id].[расширение]`

Примеры правильных имён:
- `logo_vtracer_002.png`
- `art_starvector_001.jpg`
- `noisy_scan_003.webp`

**Ограничения на имя:**
- Без пробелов
- Без кириллических символов
- Без спецсимволов (разрешены только латинские буквы, цифры, дефис `-` и подчёркивание `_`)

## Допустимые форматы и требования к изображениям
- **Форматы:** PNG, JPG/JPEG, WebP
- **Разрешение:** Минимальное разрешение изображения — **256×256 px**
- **Максимальный размер файла:** **10 MB** (для предотвращения проблем с производительностью PIL/VTracer)
- **Цветовые режимы:** RGB, RGBA. Изображения в оттенках серого (grayscale) автоматически нормализуются с помощью OpenCV.

## Инструкция по запуску пайплайна
Для деконструкции растровых файлов, генерации технических паспортов и сборки композитных векторных SVGs выполните следующие команды из корня проекта:

1. **Деконструкция и классификация (A01):**
   ```bash
   python ops/scripts/deconstruct.py
   ```
   *Скрипт проанализирует файлы в папке `input/`, определит типы слоёв и скопирует рабочие копии в `01_input_raster/high_contrast/` или `01_input_raster/complex_gradients/`.*

2. **Валидация и нормализация паспортов (A02):**
   ```bash
   python ops/scripts/validate.py
   ```
   *Скрипт проверяет соответствие JSON-схемам, присваивает COMP ID и формирует паспорта в `04_passports/`.*

3. **Векторизация и компиляция слоев (A03, A04, A05):**
   ```bash
   python ops/scripts/compile_svg.py
   ```
   *Скрипт запускает векторизаторы (VTracer / StarVector), объединяет слои в итоговый composite SVG, применяет дизайн-токены и проводит QA-аудит.*

## Дополнительная информация
- Оригинальные файлы в папке `input/` не удаляются и не перемещаются автоматически до полного подтверждения успешного выполнения сборки и прохождения всех этапов QA-аудита.
