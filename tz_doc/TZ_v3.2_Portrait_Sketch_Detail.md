# ТЕХНИЧЕСКОЕ ЗАДАНИЕ v3.2: ДЕТАЛИЗАЦИЯ SKETCH ДЛЯ ФОТОГРАФИЙ ЛЮДЕЙ

**Версия:** 3.2 (надстройка над v3.1, движок `sketch_vectorize.py`)
**Источник:** CHANGE REQUEST — улучшение детализации скетча для HUMAN_PHOTO
**Принцип:** Бесплатно, локально, детерминированно. Без нейросетей и загрузок моделей.

---

## 0. Проблема и цель `[АНАЛИЗ]`
Скетч v3.1 (одиночный XDoG по grayscale) терял черты лица: глаза/брови/нос/губы
не читались, причёска бедная, тёмная одежда вырождалась в чёрное пятно.
**Причина:** одиночный XDoG на необработанном grayscale не вытягивает
низкоконтрастные черты лица (особенно в тени) и шумит на текстуре.

**Цель:** контурный рисунок, по которому узнаётся человек — видны глаза, брови,
нос, губы, форма лица, пряди/чёлка, складки одежды, пропорции.

## 1. Выбор метода `[ФАКТ: эксперимент]`
Сравнены 3 локальных метода извлечения линий на портрете `lisa_14`:
| Метод | Черты лица | Линии | Вывод |
|-------|-----------|-------|-------|
| A. Текущий XDoG (baseline) | теряются | редкие/рваные | плохо |
| **B. CLAHE + multi-scale XDoG** | **чёткие** | хорошие | **выбран** |
| C. Flow-based DoG (Coherent Line Drawing) | размытее | очень связные | хорошо, но лицо грязнее |

Метод B победил по приоритету «узнаваемость > детализация > чистота». FDoG (C)
реализован и проверен (запас на будущее для «художественного» режима).

## 2. Реализованный пайплайн (`extract_lines`, TZ v3.2)
```
RGB → resize(work ≤1400) → bilateral (убрать текстуру/шум кожи, сохранить рёбра)
    → CLAHE (поднять слабоконтрастные черты из тени)
    → XDoG fine (черты лица + пряди волос) ∪ XDoG mid (структурные контуры)
    → удаление спеклов (connected-components < min_blob)
    → VTracer binary → чёрные пути → build_black_svg (прозрачный фон, #000000)
    → перцептивный QA SSIM(lines) ≥ 0.90
```
- **Многомасштабность** — ключ: fine-масштаб ловит глаза/ресницы/пряди,
  mid-масштаб даёт чистые контуры лица/плеч/одежды; объединение `cv2.min`.
- **CLAHE** вытягивает черты из жёсткой боковой тени (как на `lisa_14`).
- Параметры масштабируются уровнем `vector_detail_level` (ULTRA/HIGH/MEDIUM/LOW).

## 4. Результат `[ФАКТ 2026-06-13]`
`lisa_14` (HUMAN_PHOTO) перекомпилирован: SSIM(lines)=0.935, gate PASS,
прозрачный фон, только `#000000`, полностью вектор. Визуально подтверждено:
- глаза (веки + радужка обоих глаз), брови, нос (спинка/крылья/кончик), губы;
- чёлка и пряди волос, форма причёски;
- воротник/лацканы/плечи и складки куртки;
- пропорции и поза сохранены; лицо узнаваемо.

Все критерии приёмки CR выполнены. Стандарт вывода v3.1 (чёрный/прозрачный/вектор)
соблюдён.

## 5. Ограничения `[зафиксированы]`
- Линии — заливные контуры VTracer, не одно-штриховые центровые (single-stroke
  потребовал бы скелетонизации; запас на будущее).
- Очень плотные текстуры-фото (мозаика `flow_15`, ковёр `kover_05`) при HIGH
  детализации дают слишком много линий → перцептивный гейт отправляет их в
  карантин (корректно, это не портреты).
- Лёгкий текстурный шум на ярко освещённой одежде остаётся (баланс «не терять
  складки/линии» из CR). Регулируется `min_blob` по уровню детализации.
