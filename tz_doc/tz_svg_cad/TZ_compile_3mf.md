## 0. Фундамент и границы

**Надстройка над `svg_cad` (T0–T3, должен быть смержен или в базе ветки).** Вход — каноничный артефакт `svg_artifact_v1` `(S)`:

**Кого обрабатываем:** ТОЛЬКО артефакты с `3mf_eligible == true` (т.е. `STANDARD_VECTOR` ∧ монохром ∧ все сабпути замкнуты). `SKETCH_VECTOR` (`3mf_eligible=false`) — лайн-арт с тонкими штрихами, прямой солид-экструзии не подлежит → **вне области** (отдельный режим «штрих→труба/гравировка» — будущий ТЗ).

- **Вне области:** SKETCH→3D; цветной/мультиматериальный 3MF; слайсинг/G-code; Stage 3 (лонгборд, заморожен); ND-06.

## T0 — Зависимости и политика физического масштаба (R-06)
**Цель** `(G)`: зафиксировать инструментарий и единственное место, где `px→mm` превращается из `null` (зарезервировано контрактом) в число.

**Действия:**
1. Среда `(S, проверено 2026-06-19)`: установлены `shapely 2.1.2`, `numpy`, `opencv (cv2)`, `svgpathtools`, `lxml`, `resvg_py`. **Отсутствуют** `trimesh`, `mapbox_earcut`, `manifold3d`.
2. `[РЕШЕНИЕ — выбор зависимостей]` `(G, рекомендация)`:
   - **Вариант A (рекомендуется):** `pip install trimesh mapbox_earcut` — экструзия (`trimesh.creation.extrude_polygon` принимает shapely-полигон с дырами), watertight-проверки, экспорт 3MF «из коробки». Колёса под Windows есть, чисто-питон/нативные, бесплатно.
   - **Вариант B (zero-extra-dep):** триангуляция крышек через `mapbox_earcut` (минимальный пакет), а 3MF писать вручную (`zipfile` + `lxml`: 3MF — это OPC-zip с `3D/3dmodel.model`), manifold-проверки — свои (≤40 строк). Полный контроль, минимум зависимостей.
   - Решение по A/B — за владельцем (см. открытые вопросы). По умолчанию A: надёжнее и меньше своего кода.
3. **Физ.масштаб и геометрия печати** — записать в SSOT `00_governance/pipeline_config.json`, новая секция `"three_mf"`:
   ```json
   "three_mf": {
     "target_long_side_mm": 100.0,
     "extrusion_height_mm": 3.0,
     "base_plate": true,
     "base_plate_mm": 0.6,
     "polarity": "raised",
     "min_feature_mm": 0.8,
     "output_units": "millimeter"
   }
   ```
   `px_to_mm` вычисляется на артефакт: `target_long_side_mm / max(viewbox_w, viewbox_h)`; пишется в метаданные 3MF-артефакта (закрывает R-06).
4. `[РЕШЕНИЕ ВЛАДЕЛЬЦА — блокирует T2]` значения: целевой размер, толщина, base plate (да/нет + толщина), полярность (`raised` — чёрное выступает над подложкой / `cutout` — чёрное это сам объект-трафарет), `min_feature_mm` (тонкие элементы ниже порога печати).

**DoD:** зависимости установлены и импортируются; `three_mf` в SSOT; `px_to_mm` детерминирован и проверяем; расхождения с владельцем разрешены.

## T1 — SVG → корректные 2D-полигоны (с дырами)
**Цель** `(G)`: из контрактного SVG получить геометрически валидный набор полигонов «солид/пустота», устойчиво и детерминированно.

**Действия:**
1. Прочитать released SVG; распарсить `<g>`-scale и пер-путь `transform="translate"`; перевести все пути в КООРДИНАТЫ viewBox `(S, эти трансформы нельзя терять — известная грабля)`.
2. Флэттенинг кубических Безье в полилинии с допуском `(U, напр. 0.2 px)` — `svgpathtools`.
3. Сборка геометрии. **Решение** `(G, рекомендация)`: два пути, выбрать по надёжности:
   - **Вектор-first:** каждый путь → `shapely.Polygon`/мультиполигон; `shapely.make_valid` + `unary_union` всех чёрных путей → итоговая область с дырами (вложенные противо-winding сабпути = отверстия). Точно, но чувствительно к самопересечениям/winding.
   - **Растр-контур (надёжный fallback):** отрендерить SVG (`render_svg`, уже есть) в бинарную маску при DPI из `px_to_mm`; `cv2.findContours(RETR_CCOMP/RETR_TREE)` → внешние контуры + дыры по иерархии → полигоны. Детерминирует дыры без winding-рисков; цена — сглаживание уровня растра.
   Рекомендуется вектор-first с авто-fallback на растр-контур при невалидной геометрии (`not polygon.is_valid` после make_valid).
4. Очистка: удалить полигоны с площадью ниже `min_feature_mm²` (после масштабирования) — непечатаемая пыль; залогировать отброшенное.
5. **Инвариант (наследник svg_cad T3):** итог непустой; иначе артефакт → quarantine с диагностикой (не молчаливый пустой меш).

**DoD:** для тест-набора получены валидные shapely-полигоны (`is_valid==True`), дыры сохранены; пустой результат → quarantine.

## T2 — Экструзия в 3D-меш + физ.масштаб
**Цель** `(G)`: превратить 2D-полигоны в watertight-призмы, применить `px→mm`, собрать единый печатный объект.

**Действия:**
1. Масштаб: умножить координаты на `px_to_mm` (T0). Ось Y SVG вниз → инвертировать в правую СК меша.
2. Экструзия каждого полигона-с-дырами на `extrusion_height_mm`: триангуляция крышек (earcut/trimesh) + боковые стенки (по 2 треугольника на ребро контура и каждой дыры), согласованная ориентация нормалей наружу. (`trimesh.creation.extrude_polygon` делает это для полигона с дырами.)
3. **Base plate** (если `true`): тонкая подложка `base_plate_mm` под bounding box объединённой области — связывает разрозненные «острова» чёрного в один печатаемый объект (иначе плавающие куски). `polarity=cutout` → база отсутствует, экспортируется сам солид.
4. Объединение: при пересечении призм — boolean union (`manifold3d`/`trimesh`); при заведомо непересекающихся — простая конкатенация + проверка манифолдности на стыке с базой.
5. Записать `px_to_mm`, габариты (мм), толщину в метаданные.

**DoD:** меш в мм, ожидаемые габариты (`target_long_side_mm`), визуальный рендер-превью корректен.

## T3 — Валидатор манифолдности / печатопригодности (отложен из svg_cad)
**Цель** `(G)`: гейт печатопригодности — то, что svg_cad намеренно НЕ делал (там был лишь флаг `3mf_eligible`).

**Действия — независимые проверки (ось «топология-3D»):**
1. **Watertight / 2-manifold:** каждое ребро принадлежит ровно двум треугольникам.
2. **Согласованность winding / нормалей:** ориентируемая поверхность, нормали наружу.
3. **Положительный объём** (`> 0`), нет вырожденных треугольников (нулевая площадь), дубль-вершин в пределах eps.
4. **Самопересечения** — best-effort (если доступно в trimesh/manifold3d).
5. Нарушение → артефакт в `quarantine` с диагностикой (какая проверка, счётчики: незакрытые рёбра, перевёрнутые грани) — НЕ молчаливый экспорт битого меша.

**Граница** `(G)`: ремонт меша (hole-filling) — best-effort/опционально; основной контракт — детектировать и карантинить непечатаемое, а не чинить любой ценой.

**DoD:** валидный меш `is_watertight & is_winding_consistent & volume>0` → release; искусственно битый (дыра в меше) → quarantine с диагностикой; регрессионный кейс.

## T4 — Экспорт 3MF + контракт 3MF-артефакта
**Цель** `(G)`: стабильный печатный выход с провенансом, как SVG-контракт для 2D.

**Действия:**
1. Экспорт `.3mf` (OPC-zip; `<model unit="millimeter">`; меш в `<object>`/`<build>`). Вариант A — `trimesh.export(..., file_type='3mf')`; вариант B — вручную `lxml`+`zipfile`.
2. Каталог вывода `(G)`: `07_output_3mf/<stem>.3mf` (НЕ мешать с `05_output_svg/`). `staging`/`quarantine` по аналогии.
3. Сайдкар/схема метаданных 3MF: `00_governance/schemas/mesh_artifact_v1.schema.json` — поля: `comp_id`, `source_svg`, `spec_version`, `px_to_mm`, `extrusion_height_mm`, `base_plate`, `polarity`, `bbox_mm`, `volume_mm3`, `manifold` (результаты T3), `watertight:bool`. Зеркало в knowledge graph.
4. Провенанс-цепочка: `mesh_artifact` ссылается на `svg_artifact` (`output_filename` SVG), тот — на исходный растр. Полная трассируемость растр→SVG→3MF.

**DoD:** `.3mf` открывается валидатором (напр. повторный импорт trimesh / внешний слайсер при наличии); метаданные конформны схеме; зеркало в графе.

## Глобальные ограничения
- Каноничный вход — `svg_artifact_v1`; не переизобретать парсинг — использовать контракт/метаданные.
- Только `3mf_eligible==true`; режимы по умолчанию из SSOT, не хардкодить (как T0 svg_cad).
- Не трогать 2D-пайплайн (`compile_svg.py` и движки) — только читать его выход.
- Детерминированно, локально, бесплатно. Битое не экспортировать молча — карантин + диагностика.
- Минимальные диффы; конвенции каталогов/кода проекта.
