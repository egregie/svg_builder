# CHANGE REQUEST v3.5: ВОССТАНОВЛЕНИЕ РЕЖИМА РЕНДЕРА (STANDARD ↔ SKETCH FALLBACK)

**Тип:** надёжность рендера (НЕ классификатор как таковой — обходит его ошибки).
**Надстройка над:** TZ v3.1 (два движка) + понижение sketch-гейта до 0.75.
**Проблема:** часть тональных/лайн-арт изображений классификатор уводит в
STANDARD-заливку (напр. ч/б линейный портрет помечается как LOGO) — заливка даёт
плотный «blob», который не проходит перцептивный гейт и уходит в карантин.

---

## 0. Данные (замер сигналов классификатора)
14 STANDARD-провалов делятся на два подкласса:
- **детальный лайн-арт / тон** (`lap_var>600`, `flat_frac<0.75`, `edge_frac>0.04`):
  photo_011/013/024/017/009, cat_2, portal_13 — должны идти в SKETCH;
- **плоские иллюстрации** (низкий `lap_var`, высокий `flat_frac`): photo_031/062/056 —
  заливочные, SKETCH им не обязательно поможет.
Настоящие лого/иконки (постоянно проходят STANDARD) имеют `flat_frac ≥ 0.79`
(даже детальные masson/logo_pee — `flat ≥ 0.92`), т.е. хорошо отделяются.

## 1. Решение: fallback во время рендера (а не реклассификация)
Выбран **render-time fallback** (вариант «штрафовать фото/скетч→STANDARD-blob»),
а не правка классификатора, потому что он **строго безопаснее**: срабатывает
только на провале гейта и принимает альтернативу только если ОНА проходит свой
гейт. Это физически не может ухудшить то, что уже проходит (25/25 иконок des,
44 лого), и при этом возвращает мисроутнутые скетчи.

Логика в `compile_object_svg_mono` (`compile_svg.py`):
1. Рендер классифицированным режимом.
2. Если гейт НЕ пройден → рендер ДРУГИМ режимом.
3. Принять альтернативу, только если она прошла свой гейт; для SKETCH
   дополнительно `0.004 ≤ line_fraction ≤ 0.45` И `render_black_frac ≤ 0.5`.
   `render_black_frac` = доля чёрного в ОТРЕНДЕРЕННОМ рисунке (на белом) —
   честный признак «blob»: маска-линий недосчитывает, т.к. трассированные
   тёмные области заливаются шире своих пикселей. Тёмный исходник (чёрные обои)
   может пройти SSIM-гейт, но отрендериться почти сплошным чёрным — это ловится.
4. Иначе — карантин (как раньше).

Двунаправленно: STANDARD-провал → пробуем SKETCH; SKETCH-провал → пробуем STANDARD.

## 2. Метаданные
В метрики паспорта добавлены `classified_mode` (что выбрал классификатор) и
`fallback_from` (из какого режима ушли), `render_mode` = фактический режим.

## 3. Инварианты / отсутствие регрессий
- Изображения, проходящие классифицированным режимом, НЕ трогаются (fallback не
  запускается). → 0 регрессий по уже released.
- Принимается только альтернатива, прошедшая гейт → качество не падает.

## 4. Ожидаемый результат
photo_024 (ч/б портрет, LOGO→STANDARD blob, SSIM 0.91) и подобные детальные
скетчи возвращаются через SKETCH-fallback. Плоские иллюстрации и настоящие
трудные кейсы (ковёр) остаются в карантине — это корректно.
